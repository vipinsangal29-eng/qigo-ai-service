QIGO PRIVACY POLICY

आपका data, आपकी अनुमति।

यह policy बताती है कि Qigo website और Android app nearby service या shop matching के दौरान कौन-सी जानकारी इस्तेमाल करते हैं और आपको उस पर क्या control मिलता है।

हम कौन-सी जानकारी इस्तेमाल करते हैं

  • आपके द्वारा लिखी या बोली गई service/product requirement।
  • आपकी अनुमति के बाद approximate या precise location, केवल nearby matching के लिए।
  • आपके द्वारा चुनी गई material list, photo, PDF या text attachment।
  • चुने गए provider/seller, quotation और booking से जुड़ी app activity।
  • Customer/partner registration में दिया गया नाम, mobile number, शहर, service और consent status।
  • Website counter के लिए randomly generated visitor ID और page-view count; इसमें आपका नाम या mobile शामिल नहीं होता।
  • Security और reliability के लिए basic device, browser और network diagnostics।

जानकारी का उपयोग

Qigo requirement समझने, nearby eligible professionals या sellers खोजने, estimated rate, availability, distance और ETA compare करने तथा चुनी गई booking/order screen दिखाने के लिए जानकारी इस्तेमाल करता है। Qigo आपकी personal information बेचता नहीं है।

Location और attachments

Location permission optional है और search शुरू करते समय मांगी जाती है। Permission बंद होने पर live nearby matching सीमित हो सकती है। Attachment केवल तब access होता है जब आप phone के file picker से स्वयं file चुनते हैं।

Accident और emergency mode

Accident mode में location का उपयोग nearby hospital, police station, taxi, towing और workshop links बनाने के लिए किया जा सकता है। Vehicle photos और incident details तभी access होते हैं जब आप स्वयं चुनते या भरते हैं। Current demo photos को server, police, ambulance, insurer या agency को transmit नहीं करता। Production में हर recipient के लिए अलग consent, encryption और deletion control दिया जाएगा।

Photo/AI result केवल preliminary assistance होगा; यह medical diagnosis, vehicle roadworthiness certificate या official accident assessment नहीं है। Immediate danger में official emergency number 112 use करें।

Registration और website counter

Customer या partner registration submit करने पर नाम, mobile, शहर/area, चुनी हुई service, partner service radius और consent status Qigo database में save होते हैं। Registration का status mobile/document verification पूरा होने तक pending रहता है; form submit करना OTP verification नहीं माना जाता।

Visible website counter unique browser installations का approximate count दिखाता है। इसके लिए आपके browser में एक random ID रखी जाती है और server केवल उस ID के first/last visit तथा view count को रखता है। Counter exact लोगों, households या verified accounts की संख्या नहीं है।

Current early-access release

अभी: registration और visitor counter database-backed हैं। Matching, quotations, provider movement, OTP, payment और most booking states अभी demo/prototype हैं। Registration save होना verified account या confirmed service booking नहीं है।

Third-party services

Route और map preview के लिए Google Maps services इस्तेमाल हो सकती हैं। Hosting, Android WebView और Google Maps अपने security/diagnostic data को अपनी policies के अनुसार process कर सकते हैं।

Storage, security और deletion

Qigo HTTPS connection इस्तेमाल करता है। Current release में booking state आपके device के local storage में रह सकती है। App data clear करने या app uninstall करने पर local booking और visitor ID हट जाती है, लेकिन पहले से submit registration server पर रहता है। Registration access, correction या deletion request के लिए नीचे दिए address पर reference number और registered mobile के last four digits के साथ संपर्क किया जा सकता है।

बच्चों की privacy

Qigo सामान्य household service discovery के लिए है और 13 वर्ष से कम उम्र के बच्चों के लिए निर्देशित नहीं है। हम जानबूझकर बच्चों का personal data collect नहीं करते।
